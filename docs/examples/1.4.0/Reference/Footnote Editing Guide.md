# Footnote Editing Guide

This guide uses a named reference[^editing] and a numbered one[^1].

## Edit a definition

Click a superscript reference in Write. Its definition field receives focus. Edit the text, or add a new line; continuation indentation is added when it saves.

## Keep the source

Use Markdown to add or rename a definition. Existing labels, tabs, spacing and blank lines remain exact when you edit the body of a supported note.

Inline asides and unsupported layouts still open in Markdown with an explanation.

Try [[Lab/Footnote Notebook]] and [[Reading/Field Observation Sources]] next.

[^editing]: Definitions accept Markdown text, including **emphasis**.
    Changes autosave and can be undone.

[^1]: The reference button also works with keyboard focus and Enter.
