# Task Status Workshop

Use the small status picker beside each task in Write. It lists Open, Done, Question, In progress, Cancelled, Deferred and Important. Open and Done also have a checkbox.

- [ ] Plan the review
- [X] Keep this uppercase marker until its status changes
- [?] Does the draft explain the decision?
- [/] Revise the introduction
- [-] Drop the duplicate section
- [>] Save the appendix for later
- [!] Check the final numbers
- [z] Preserve an unfamiliar marker too

## Nested work

- [?] Review the evidence
  - [/] Read the field notes
  - [!] Check the source dates
- [>] Schedule the follow-up

Try changing a status, then use Undo in the main editor. Switch to Markdown to inspect the exact markers, or Preview to read the styled task marks.
