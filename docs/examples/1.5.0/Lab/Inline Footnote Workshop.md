# Inline Footnote Workshop

A short aside stays beside the thought that needs it.^[This is an inline footnote. Its original Markdown stays inside the note.]

Click the small **note** superscript in Write. Edit its Markdown, then choose Apply. Cancel or Escape leaves the saved footnote alone.

A longer aside can keep **formatting** and links.^[Try **bold**, *italic* and [a source](https://example.com). Nested [square brackets] and escaped \[literal brackets\] also stay exact.]

One inline footnote can span a single line break.^[First line of the aside.
Second line, with two trailing spaces preserved here.  ]

Named references work alongside inline asides.[^source] Click **source** to reach the definition below.

[^source]: Named footnotes use a Markdown field too.
    Continuation lines keep their indentation.

## Try it

- Edit an inline aside and choose Apply.
- Open it again, make a change, then Cancel.
- Undo an applied edit from the main note.
- Switch to Markdown to see the exact `^[…]` source.
- Switch to Preview to read the numbered footnotes.

See [[Lab/Footnote Notebook]] for more numbered and named examples.
